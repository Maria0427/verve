Одностраничный сайт (лендинг) для фитнес-студии «Verve» с формой записи и автоматической отправкой заявок в ВКонтакте через API.
Демо: https://verve-5fnb.vercel.app/

О проекте
Verve — это landing page для онлайн-студии здорового тела, предлагающей три направления: растяжка (Stretching) и миофасциальный релиз (МФР) и здоровая спина.
Сайт разработан для привлечения клиентов и сбора заявок на тренировки.
Главная фишка проекта — интеграция с VK API: заявки из формы автоматически отправляются администратору в личные сообщения ВКонтакте. 
Это позволяет владельцу студии быстро обрабатывать запросы без необходимости заходить в админку сайта.

Технологии
Язык разметки: HTML5
Стили: CSS3 
Язык программирования: JavaScript 
Бэкенд: Node.js (серверная функция для Vercel)
API: VK API (отправка сообщений в группу/личные сообщения)
Хостинг: Vercel
